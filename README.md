# customer-batch

This workspace contains a basic Java project named `customer-batch` created under `C:\new-workspace`.

## Build

- Use Maven: `mvn clean package`
- Run: `mvn exec:java -Dexec.mainClass="com.example.App"` (requires Maven Exec Plugin)

## Project structure

- `pom.xml`
- `src/main/java/com/example/App.java`
- `src/test/java/com/example/AppTest.java`
